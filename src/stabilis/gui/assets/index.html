columns

Tick a column to draw it. Names are yours to change — whatever you type here is what the expressions in stage 2 refer to.

the record

Drag to keep a stretch. Drag again to keep another. Shift-drag pans, the wheel zooms, double-click fits. Zooming asks the server for finer detail over the visible span — it is not a magnified picture.

what the numbers are

cleanup

Off, each window is analysed as its own record and drawn as its own curve. On, they become one record with the stretches between them marked as gaps. Nothing is interpolated either way.

series

Each series is an arithmetic expression over the columns: NCS - VSL, -VSL, (A - B) / 5, #2 * 1e9. Click a name to insert it.
