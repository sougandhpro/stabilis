stabilis

columns

Tick a column to draw it. Names are yours to change — whatever you type here is what the expressions in stage 2 refer to.

the record

Drag to keep a stretch. Drag again to keep another. Shift-drag pans, the wheel zooms, double-click fits. Zooming asks the server for finer detail over the visible span — it is not a magnified picture.

what the numbers are

cleanup

Off, each window is analysed as its own record and drawn as its own curve. On, they become one record with the stretches between them marked as gaps. Nothing is interpolated either way.

series

Each series is an arithmetic expression over the columns: NCS - VSL, -VSL, (A - B) / 5, #2 * 1e9. Click a name to insert it.

clocks

The oscillators, masers and GPSDOs on the bench. An id is all that is needed; it is what the measurements below refer to.

instruments

Channels belong to an instrument because that ownership is what makes the common-mode check possible — two channels of one counter share a timebase, an LO and a supply, so their noise does not cancel in the hat. Leave a floor blank to solve for it; a back-to-back run measures it from data.

bench file

Saving hands the file to your browser's downloads — this server reads your disk and never writes to it. What comes down is what stabilis bench check reads.

measurements

One row per record: two clocks, one channel. Naming the same clock at both ends is legal and useful — that is a back-to-back run, and it is how a channel's noise floor gets measured rather than assumed.

can this bench separate its clocks?

Answered from the graph alone, before any file is read — which is while the answer is still cheap to act on.
